Sift

A command-line tool for querying structured logs. Point it at JSON, logfmt or CSV, write a filter in one line, and get back only the records you asked for.

MIT licenceLinux, macOS, WindowsSingle static binary, 6 MB

Install

Download 2.4.0 Released 14 October 2026
$ curl -fsSL sift.sh/install | sh

Or with a package manager:
brew install sift
cargo install sift-cli
scoop install sift

1

Get started

Three commands take you from a raw log file to a filtered, readable result. Each one builds on the last.

1.1

Look at the shape

Sift reads the first records and reports which fields exist and what type each one has.

$ sift schema app.log
ts       time    1,000 of 1,000
level    string  1,000 of 1,000
status   int       812 of 1,000
path     string    812 of 1,000
1.2

Filter the records

Write a condition with the field names you just saw. Comparisons, ranges and regular expressions all work.

$ sift 'status >= 500' app.log
09:14:02 error 503 /api/orders
09:14:07 error 502 /api/orders
09:20:51 error 500 /api/cart
1.3

Count and group

Pipe the result into an aggregation. Output is a plain table, or JSON with --json.

$ sift 'status >= 500' app.log \
    | sift count by path
path          count
/api/orders      41
/api/cart         6
2

How it works

Sift streams. It never loads a whole file into memory, so a 40 GB log costs the same memory as a 40 KB one.

Formats
JSON lines, logfmt, CSV, TSV. Gzip and zstd are decompressed on the fly.
Throughput
About 900 MB per second per core on JSON lines, measured on a 2024 laptop.
Memory
Constant for filtering. Grouping grows with the number of distinct keys, not records.
Exit codes
0 matches found, 1 no matches, 2 error. Safe to use in scripts.

Commands

Every command reads files named on the command line, or standard input when none are given.

CommandWhat it doesExample
siftPrint records that match a filtersift 'level == "error"'
sift schemaList fields, types and how often each appearssift schema app.log
sift countCount records, optionally groupedsift count by host
sift statsMin, max, mean and percentiles of a number fieldsift stats latency_ms
sift pickKeep only the named fieldssift pick ts,path
sift tailFollow a growing file and filter new linessift tail -f app.log

Common flags

--json
Write output as JSON lines.
--since
Only records after a time, e.g. --since 2h.
--format
Skip detection and name the format.
--limit
Stop after this many matches.

Quote your filters

Shells treat > as redirection. sift status > 500 app.log creates a file called 500 instead of filtering. Wrap the filter in single quotes.

5

Help

Built-in help is the fastest route. Every command accepts --help, and sift explain describes what a filter will do before you run it.

$ sift explain 'status >= 500 and path ~ "^/api"'
keep records where
  status is a number at least 500
  and path starts with "/api"
