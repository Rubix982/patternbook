patternbook

A library of design knowledge learned from human-made work, for coding agents. These pages run in the browser; the library itself and every test result are in the repository.

  • Studio: every style in the engine, with its dials: the 214 of Mursal Furqan Kumbhar's Lumenary, and patternbook's own.
  • Contact sheet: every still style on one picture.
  • Our print treatments: press, risograph, halftone, pen hatching.
  • The C-011 winning page: a router troubleshooting page built with the PS Magazine style.
  • The C-008 winning page: the same brief, with the IKEA line-art style.
