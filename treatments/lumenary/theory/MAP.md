## Exercise

Pick a treatment. Read its *The mathematics* section, then its code. For each number in the
code, mark it **physics** (comes from how the process works, like the square root in halftone) or
**tuned** (chosen by eye, like halftone's 1.06). Then check whether the theory equation is the one
the code actually runs. Worked example: halftone. The code is `r = sqrt(adjust(1 − lum)) · s · 0.5 · gain · 1.06`;
the theory says r = ½ s g 1.06 √(adj(1−L)). They match. √ is physics; 1.06 is tuned (the exact value would be 2/√π ≈ 1.128).
