# Architecture

_Enumerated from sources in card C-015 (2026-11-22); merged from three passes whose full output and request logs are in `runs/c015/`. Every element has at least one source that names it. Regions are as the sources state them (historical region; modern country). Candidate branches are named varieties a source gives, many of them geographical-indication products; they become branches once samples show them (`docs/atlas.md`). "First pass" says whether the element was in the sketch written from memory that the card checked. Limits: `atlas/README.md`._
